## A. 사용자 작업·소통 규칙 (모든 에이전트 준수)

1. **교정 5규칙**: ① 답만 ② "진행/네" 1회 = 확정(재질문 금지) ③ 중복 질문 X ④ 사실만 ⑤ 헛소리 X. 욕설/불만 신호 = 즉시 중단 + 검증.
2. **DECISION LOCK**: "네/진행/진행해/고고/OK/응/그래/맞아" 1회 응답 = 확정. 오류 시에만 중단·보고. (동의어 기준: appdata판 B의 상세 목록)
3. **단순성 우선(D7)**: 기존 스킬/API/웹 UI 버튼 우선 사용. 복잡한 재구현 금지. "하지 마 / 벌써 작업했어" = 즉시 중단.
4. **검증 3금지**: 도구 출력 없이 verify 금지 / "이미 알고 있음"으로 스킵 금지 / 추측 금지. Verify = console + API + snapshot.
5. **비용 의식**: 비싼 모델 = 복잡 작업만. 저가 모델 + Runbook 선호. 429/403/402 잦은 free 모델 회피, 안정 경로 우선.
6. **설명 스타일**: 비유 + 표 + 한 줄 요약. 길게 반복 실패 시 재요약. 이중 답변 금지.
7. **데이터 일관성**: 매핑(금형번호→제품명 등)은 모든 시스템 자동 반영. 금형번호 = 제품 unique ID. DB 직접 조회 우선(추측 금지), 단 ORM 직접 탐사 금지(조회 API 우선).

## B. VF 도메인 지식 (현재 VF-new 유효)

- **현재고 SoT**: `GET /api/master/specs`의 `current_stock`. 조회 스크립트 `backend/scripts/vf_product_lookup.py`. ⚠️ 20XX번(=320-A1-2-XX)은 스크립트 미지원 → `location=320-A1-2-XX` 직접 조회. 2034번 = 2-34 (≠234번).
- **출차(departure)**: `VehicleOrderService` 단일 진입점. PDF = `{plate}_{date}.pdf`, 봉인씰 = plate + date. 출차 ≠ 끝(후속 작업 있음).
- **LS 배차 메시지**: `{HUB} {톤수} {시간} {호차}차` + "배차요청드립니다". KPP = 스킬 스크립트(`wpps_register_2_3.py`) 우선, 직접 CDP 신규 작성 금지.
- **KPP PBM140**: 다중 센터 공용(타 센터 전표 존재 가능). 1호차 = 호차순 강제 아님. 기존 행 보존 + 맨 끝 신규 행. 등록 시 호차만 보지 말고 **차량번호도 함께 확인**(by_both, kpp_session.py).
- **권역 입력**: G=GMH, M=MIDDLE. 합산 = 기존값 덧셈. 저장 = `POST /api/vehicle-extras` (NOT ls-data). payload `{date, extras:{호차:{plt,regions,departTime,pltTime}}}`. departTime/pltTime = 현재 HH:MM 필수. POST 전 GET으로 기존값 읽어 덮기.
- **워크박스 EU** (320-A1-1-6XX): 650=Y2, 689=B4, 690=Y9, 691=R2, 692=B2, 693=Y4, 694=R4, 695=Y6, 696=R6, 697=B6, 698=R9, 699=B9. color1 = "EU - RED/BLUE/YELLOW".
- **입고 제한**: 기본 = `default_inbound_limit_qty` (04:00, 90일 + 추이×4). min2 = 출고 없을 때만. 수동 = `limit_qty`. 실시간 평균 금지.
- **VF-new 운영**: Django+React, 포트 5174(프론트)/5176(백엔드). 메뉴 SoT = dashboard `NAV_ITEMS`. 메뉴 맨 아래 = 트럭운송비 → 제품배치도(`/product-display`).
- **VF 전용 도구 우선**: VF 작업 지시는 VF MCP 도구(`mcp__vf_*`) 우선. import server.py 우회·브라우저 탐색 지양. (도구명은 현재 Linux MCP 구성에서 재확인 후 사용)
- **모델/도구 평가**: 추가 결제 0, 공식 BYOK/base_url 지원 여부 우선. 유튜브(한국 LLM 코딩) = 요약 + 우리 환경 적용 검토만. 같은 주제 후속 링크 = 이전 대비 변경점만 보고.
