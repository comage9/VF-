## 1. 핵심 원칙 — L1/L2/L7/A/C 등 내부 이름 전부 폐기

- 화면·데이터·검색·엑셀·이동 전부에서 **내부 존ID(L1, L7, A-X1 등) 노출 금지**.
- 좌표는 **배치도 전체 그리드의 순수 X축·Y축 숫자**로만 표현.
- (내부 구현에 라인/존ID가 남아 있더라도, 사용자에게는 X·Y 숫자만 보인다.)
- **모든 칸과 통로는 각각 하나의 (X,Y) 좌표를 가진다.** 통로도 예외 없이 좌표 보유 → 격자 전체가 빠짐없이 좌표로 덮임.

## 2. 좌표축 정의 (주현 김 확정)

**X축(가로)**
- 왼쪽 → 오른쪽으로 갈수록 **값 증가**.
- X = 1이 **왼쪽 끝**, X = 9가 **오른쪽 끝**.
- 모든 열(칸·통로 포함)이 각각 고유 X를 가짐.

**Y축(세로)**
- 아래 → 위로 갈수록 **값 증가**.
- 아래쪽 Y=1부터 시작, 위로 갈수록 커져 **최상단 Y=21**.
- **Y=2는 통로** — 그러나 통로도 하나의 좌표 셀로서 그 자리에 (X,2) 고유 좌표를 가진다. Y=1과 Y≥3에는 제품 배치 가능(통로는 최하단이 아니며 진입/이동 경로).
- **마지막(상단) 칸에도 제품 위치 가능** → 모든 칸이 좌표 보유.

**좌표 표기 (2026-09-03 23:21 확정)**: 화면·검색·툴팁·엑셀·입력 전부 **`X<값>, Y<값>`** 접두어+쉼표 형식. 예: `X9, Y21` / `X1, Y3`. (하이픈 `9-21` 또는 `(9,21)` 금지 — X/Y 어느 축인지 명확히 하기 위해 접두어 필수)

## 3. 변환 규칙 (DB 픽셀 → 좌표, 스냅샷 v326으로 검증)

배치도 영역은 실제 격자(SLOT) 기준: 칸 폭 48px, 높이 34px, 세로 간격(gapY) 4px → **세로 한 칸 주기 = 38px**. 상단 패딩 padT=48, 왼쪽 padL=28.

**Y(행) — 전역 공통 행 번호 (열마다 독립이 아님)**
- 각 열(라인)의 칸들은 동일한 픽셀 "top 레벨"을 공유 → 같은 top은 **모든 열에서 같은 Y**.
- Y = 1 은 배치도 최하단 실제 칸 줄. 위로 38px마다 +1. 최상단 = 21.
- **Y = 2는 통로로 비어 있음.**(해당 top 레벨엔 실제 칸이 없거나 배치 금지)

검증(예시 4개):
| 제품 | 실제 존 | top+17 | Y (아래에서 계산) | 주현님 예시 | 일치 |
|---|---|---|---|---|---|
| 1 | A-L1-19 | 65 | 21 | (9, 21) | ✅ |
| 3 | A-L1-18 | 103 | 20 | (9, 20) | ✅ |
| 242 | A-L6-1 | 749 | 3 | (1, 3) | ✅ |
| 202 | A-L5-1 | 749 | 3 | (3, 3) | ✅ |

**공식**: `Y = Y_bottom_row + (top_bottom - (top + 17)) / 38`
- top+17: 칸 중심 세로 좌표
- top_bottom: 최하단 실제 칸 줄의 중심(top + 17)
- Y_bottom_row: 최하단 줄의 Y 배정치(아래쪽 세는 기준)

**X(열) — 전역 열 번호**
- 픽셀 left를 좌→우로 클러스터 → X = 1(왼쪽 끝) ~ 9(오른쪽 끝).
- 실측 열 left 그리드: [28, 80, 132, 184, 236, 288, 340, 392, 444] → 각각 X=1~9.

## 5. 구현 시 필수 규칙 (좌표 계산 함수 요구사항)

1. **전역 좌표계 1개**: `coordOf`(화면) / `coordOfAll`(검색) / 엑셀 / 좌표이동이 **같은 함수**에서 X·Y를 계산 → 이 문서 §3 공식 사용.
2. **동(dong) 구분 없이** 배치도 좌표(X·Y)로 통일. (단, A동은 좌표 공식이 위와 같고 B/C/D동은 상대 좌표 체계일 수 있어 이 문서 §3을 A동 및 공통에 적용할지 확정 필요)
3. **coordToZoneAll은 1:N 중복을 숨기지 말 것** (좌표 충돌 시 모두 노출/오류 표시).
4. 칸 이동(드래그) 후에도 **좌표는 그리드 위치 기준으로 재계산**, 번호(locNo)와 분리.
5. Y=2 통로 표시는 좌표 라벨에 반영하되 배치 금지 처리.

## 5-1. Y 원점·그리드 실측 (2026-09-03 22:50 확정, DB v326 검증)

A동 그리드를 아래→위로 38px 행별 실측한 결과 **정확히 21행**이며 Y=2가 유일한 통로(빈 줄):

```
Y=21(최상단) 칸 있음
Y=20 ~ Y=3  칸 있음 (라인별 최하단 슬롯이 Y=3에서 시작하는 라인도 있음 — 예: A-L6-1=Y3)
Y=2  통로(빈 줄) — 칸 없음
Y=1(최하단) 칸 9개 있음 (예: A-L3-17)
```

(공식 핵심)
- Y 는 **물리 그리드의 연속 행**(점유 여부 무관, 통로 포함). 아래(가장 큰 center-top)=1, 38px 마다 +1, 최상단=21.
- 즉 좌표 Y 계산은 **"실제 칸이 점유한 top레벨만 세는 것"이 아니라, 그리드 최하단~최상단 38px 전체 행을 세야** 한다. 점유만 세면 Y=2(통로)가 빠져 전체가 1행 밀림(+1 부족).
- 예시 대조 모두 통과: 제품1(최상단)=Y21, 제품3=Y20, 제품242(A-L6-1, Y3행 시작라인 최하단)=Y3, 제품202(A-L5-1)=Y3.
