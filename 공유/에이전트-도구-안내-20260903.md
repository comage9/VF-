## 1. Archify — 아키텍처 다이어그램 생성 스킬

**무엇인가**: 코드베이스/시스템 설명/설계 요구 → 검증된 인터랙티브 다이어그램(셀프컨테인 HTML + SVG) 자동 생성.
지원 다이어그램: `architecture` · `workflow` · `sequence` · `dataflow` · `lifecycle` (+ Mermaid 입력 변환/미화).
테마: dark/light, 프리셋 4종, PNG/JPEG/WebP/SVG/WebM export. (출처: tt-a1i/archify, MIT, ★45k, 2026-09-02 갱신)

### 설치 상태 (완료)
| 대상 | 위치 | 상태 |
|---|---|---|
| 공용 (canonical) | `~/.agents/skills/archify/` | ✅ v2.17 |
| Hermes Agent | `~/.hermes/skills/archify` → symlink | ✅ |
| OpenClaw | `~/.openclaw/skills/archify` | ✅ |
| OpenCode 외 (Amp, Cline 등 +12) | universal | ✅ |

### 사용법
- 자연어로 직접 요청: *"archify 써서 VF-new 백엔드 아키텍처 다이어그램 만들어줘"*
- 저장소 분석: *"archify로 이 저장소의 런타임 아키텍처 high-level 다이어그램"*
- 산출물: `.archify-out/` 폴더에 standalone HTML (브라우저로 열어 공유 가능)
- 검증: `node ~/.agents/skills/archify/bin/archify.mjs validate <type> <candidate.json> --quality showcase --json`
- 상세 스킬 규칙은 `~/.agents/skills/archify/SKILL.md` 참조 (스키마: `schemas/`, 예시: `examples/`)
- 특정 다이어그램 하나만 만들 때는 해당 스키마 + 예시 1개만 읽고 생성 (문서 과다 로딩 금지 — 스킬 자체 지침)

## 2. OpenCode — 코딩 에이전트 CLI

- **설치 상태**: `opencode` 1.18.27 @ `~/.npm-global/bin/opencode`, 설정 `~/.config/opencode/opencode.jsonc`
- Hermes도 하위 에이전트로 위임 가능 (`autonomous-ai-agents/opencode` 스킬)
- 용도: 코드 작성/수정/PR 등 코딩 작업 위임. VF-new 등 대형 코드 변경 시 **공유 규약 승인 게이트** 준수 후 사용.

### 주의
- OpenClaw·Claude Code가 같은 파일을 동시에 작업하면 충돌 → 작업 전 `공유/작업현황.md` 필독·갱신 (에이전트-협업-규약 §3)
- 새 도구 도입 시: GitHub 공개·라이선스·문서 확인 → 설치 → 공유 문서에 기록 (이 문서가 그 예)
