# 출력 이력 (PrintLog) 추가 (2026-08-10)

## 배경
- 출차 대시보드 LS/KPP 출력 시 "누가 언제 출력했는지" 기록이 전혀 없음
- "출력됐나?" 질문에 답할 수단 부재 → 로그 기능 추가

## 구현
| 항목 | 내용 |
|------|------|
| 모델 | `PrintLog` (departure/models.py) — date/hoche/plate/kind/job_title/ok/printer/client_ip/results/created_at |
| LS 기록 | `api_print()` 성공/실패 시 저장 |
| KPP 기록 | `api_print_kpp()` 성공/실패 시 저장 |
| 조회 API | `GET /departure/api/print-logs?date=&kind=&limit=` |
| UI | 대시보드 봉인씰 카드 아래 🖨️ 출력 이력 패널 (출력 후 자동 갱신) |
| admin | PrintLogAdmin 등록 |

## 검증
- tools: 2건 테스트 생성 → API 조회 → 삭제
- 브라우저: 출력 이력 패널 정상 렌더 (성공/실패 배지, 호차, 차량번호, 시각, 프린터)
