# VF 출차관리 권역별 수량 음성 합산 입력 + LS/KPP 인쇄

> 작성일: 2026-08-03
> 목적: **저사양 모델도 이 문서만 읽고 그대로 실행할 수 있게** 하는 실행 매뉴얼(Runbook)
> 대상: 텔레그램/채팅으로 사용자 말을 받아 에이전트가 대신 입력·인쇄

## 1. 사용자 요구사항 (정리)

**핵심:** 사용자가 **호차와 권역별 수량을 말하면**, 에이전트가 **파싱 → 합산 → 저장**.
인쇄(LS/KPP)도 사용자 말 한마디면 에이전트가 대신 실행.
**이 모든 것을 저사양(저비용) 모델도 이해하고 수행할 수 있어야 함.**

### 1.1 입력 시나리오
- 먼저 **호차**를 부른다 (예: "2호차")
- 이어서 **권역 + 수량**을 부른다 (예: "이스트 하나, 웨스트 하나, 미들 하나")
- 여러 번 부르면 **동일 권역은 기존 값에 합산** (덮어쓰기 ❌)
- 기본: 2호차에 총수량(plt)이 먼저 들어가는 구조. 지금은 출차카드 테스트 중이라 임의 입력.

### 1.2 합산 예시
| 호출 | 입력 | 결과 |
|:----:|:-----|:-----|
| 1회차 | "2호차에 이스트 하나, 웨스트 하나, 미들 하나" | EAST=1, WEST=1, MIDDLE=1 |
| 2회차 | "이스트 두 개, 웨스트 두 개, M 두 개" | +EAST=2, +WEST=2, +MIDDLE=2 |
| **최종** | — | **EAST=3, WEST=3, MIDDLE=3 (합계 9P)** |

### 1.3 권역 약어 매핑 (사용자 규칙)
| 사용자가 말하는 것 | 저장 코드 |
|:-----|:-----|
| 이스트 / EAST | `EAST` |
| 웨스트 / WEST | `WEST` |
| 미들 / M | `MIDDLE` |
| GMH / G | `GMH` (**'G' = GMH 확정, 2026-08-03 사용자**) |
| DGU / D | `DGU` |
| GZJ | `GWJ` |
| 야마토 / TDG 야마토 | `TW_YAMATO` |

> ✅ 약어 확정 (2026-08-03 사용자): **'G' = GMH**. 미들은 '미들' 또는 'M' 둘 다 `MIDDLE`.

## 3. 저사양 모델 실행 매뉴얼 — 권역 수량 입력 (Runbook)

**트리거 예시 문장:** "2호차 이스트 하나 웨스트 하나" / "1호차 M 둘, 야마토 셋" / "2호차에 G 하나 D 하나"

### Step 0. 날짜 결정
```
작업일 = 오늘. 단, 자정~06:00 사이라면 어제. (06:00 작업일 기준)
DATE = YYYY-MM-DD 형식
```

### Step 1. 사용자 말 파싱
1. **호차 추출**: "N호차"에서 숫자 N (없으면 이전 메시지의 호차 유지. 그래도 없으면 사용자에게 물어볼 것)
2. **권역+수량 추출**: §1.3 매핑표로 권역 코드 변환
3. **수량 한글 → 숫자**: 하나/한개=1, 둘/두개=2, 셋/세개=3, 넷=4, 다섯=5 … (아라비아 숫자면 그대로)
4. 파싱 결과 예: `{hoche: 2, adds: {EAST: 1, WEST: 1}}`
5. 못 알아들으면 **추측 금지** — 사용자에게 다시 물어볼 것

### Step 2~4. 조회 → 합산 → 저장 (python urllib — 한 번에 실행)

> ⚠️ git-bash curl 한글 JSON body = cp949 깨짐 → **반드시 python urllib 사용**

```python
import urllib.request, json
from datetime import datetime

DATE = "2026-08-07"          # 작업일 (06:00 기준)
HOCHE = "2"                  # 수정할 호차
NOW = datetime.now().strftime("%H:%M")

# Step 2: GET 기존값 전체
url = f"http://127.0.0.1:5176/departure/api/vehicle-extras?date={DATE}"
req = urllib.request.Request(url)
with urllib.request.urlopen(req, timeout=5) as resp:
    existing = json.loads(resp.read().decode("utf-8"))
extras = existing["extras"]

# Step 3: 합산 (기존값 + 입력값)
if HOCHE not in extras:
    extras[HOCHE] = {"regions": {}}
if "regions" not in extras[HOCHE]:
    extras[HOCHE]["regions"] = {}

# 예: 이스트 3개 추가
extras[HOCHE]["regions"]["EAST"] = extras[HOCHE]["regions"].get("EAST", 0) + 3
extras[HOCHE]["regions"]["GMH"]  = extras[HOCHE]["regions"].get("GMH", 0) + 2

# Step 4: 시간 설정 (필수 — 안 넣으면 출차시간/출고시간 빈칸)
extras[HOCHE]["departTime"] = NOW   # 권역 입력 시각
extras[HOCHE]["pltTime"] = NOW      # 파레트 입력 시각

# 전체 POST (기존 호차 모두 포함 — 덮어쓰기 방지)
payload = {"date": DATE, "extras": extras}
req = urllib.request.Request(
    "http://127.0.0.1:5176/departure/api/vehicle-extras",
    data=json.dumps(payload).encode("utf-8"), method="POST"
)
req.add_header("Content-Type", "application/json")
with urllib.request.urlopen(req, timeout=5) as resp:
    json.loads(resp.read().decode("utf-8"))
```

### Step 5. 검증 (필수 — POST ok:true만 믿지 말 것)
```python
# GET으로 재조회하여 값 확인
url = f"http://127.0.0.1:5176/departure/api/vehicle-extras?date={DATE}"
req = urllib.request.Request(url)
with urllib.request.urlopen(req, timeout=5) as resp:
    check = json.loads(resp.read().decode("utf-8"))
print(json.dumps(check["extras"][HOCHE], ensure_ascii=False))
```

```
예: "2호차 저장 완료 — EAST 3 / WEST 3 / MIDDLE 3 (합계 9P)"
```

## 4. 저사양 모델 실행 매뉴얼 — LS 인쇄 (Runbook)

**트리거 예시:** "1호차 LS 인쇄" / "2호차 LS 찍어"

### ✅ 인쇄 방식 확정 (2026-08-09)
| 방식 | 사용 | 이유 |
|------|:----:|------|
| **API 직접 호출** (`/api/print/{hoche}`) | ✅ 표준 | 빠름 + 봉인씰 합성 포함 |
| 웹 UI 버튼 클릭 (Playwright) | ❌ 비표준 | 느림·팝업 확인 단계 불필요 |
| 구 GDI 비트맵 인쇄 | ❌ 폐기 | 300dpi 래스터 → **품질 현격 저하** |

**서버 인쇄 엔진 (2026-08-09 수정):**
- 이전: PDF → PyMuPDF 300dpi 비트맵 → win32ui GDI 출력 (품질 저하)
- **현재:** `win32api.ShellExecute("printto", pdf, "Canon G2010 series")` — **PDF 벡터 원본 전송**
- 코드: `backend/departure/views.py` → `_print_pdf_on_server()`
- Windows 기본 프린터(ZM600 라벨) 함정 회피: 프린터 이름 명시 필수

### 전제 조건
- 백엔드 5176 실행 중
- 해당 날짜 LS PDF 존재: `backend/departure/data/ls_pdfs/{DATE}/{plate}.pdf` (차량번호로 매칭)
- 봉인씰 번호가 필요하면 사용자가 불러줌 (좌익/우익/뒷문 3개). 없으면 GET ls-data의 `seals` 사용

### 실행 (표준 · 권장)
```bash
# 1) 봉인씰 조회
# GET http://localhost:5176/departure/api/ls-data?date={DATE} → data[hoche-1].seals

# 2) 인쇄 (API 1회)
curl -s "http://localhost:5176/departure/api/print/{HOCHE}?plt={파렛트수}&date={DATE}&seal_leftWing={L}&seal_rightWing={R}&seal_backDoor={B}"
```
- `plt`: 파렛트 수량. 모르면 GET ls-data / vehicle-extras의 `plt` 값 사용
- 봉인씰 3개는 옵션 — 없으면 생략 가능 (생략 시 합성 없이 원본 인쇄)
- 서버가 알아서: 호차→차량번호 조회 → PDF 본문 매칭 → 봉인씰 합성 → **printto 벡터 인쇄**
- 응답: `{ok: true/false, hoche, results: [...], server_print: true, printer: "Canon G2010 series"}`
- 성공 메시지 예: `✅ 서버 printto 전송: Canon G2010 series · ...`
- sealed PDF 생성 확인: `ls_pdfs/{DATE}/{plate}.pdf.sealed.pdf` 타임스탬프

### 실패 시
- `차량 정보 없음` → 해당 날짜/호차 데이터 없음. GET ls-data로 먼저 확인할 것
- PDF 없음 → `ls_pdfs/{DATE}/` 폴더에 차량번호.pdf 있는지 확인할 것
- printto 실패 → Acrobat/Edge PDF 핸들러·Canon G2010 연결 확인

## 7.5 ⚠️ API 입력 시 주의사항 (2026-08-07 발견·확정)

### 문제 1: 출차시간/출고시간 빈칸
- **원인:** 웹 페이지 수기 입력 시 JS가 `new Date()`로 현재 시각 자동 기록. API POST 시 시간 미포함 → 빈칸
- **해결:** POST 시 `departTime`(출차시간), `pltTime`(출고시간)에 현재 시각 `HH:MM` 포함

### 문제 2: 기존 호차 데이터 소실 (덮어쓰기)
- **원인:** `POST /api/vehicle-extras`는 전체 extras를 덮어씀. 일부 호차만 POST → 다른 호차 소실
- **해결:** POST 전 반드시 `GET /api/vehicle-extras?date=`로 **전체 기존값** 읽고, 수정할 호차만 갱신 후 전체 POST

### 올바른 API 호출 시퀀스 (python urllib 사용 — git-bash curl 한글 깨짐)
```python
import urllib.request, json
from datetime import datetime

DATE = "2026-08-07"
NOW = datetime.now().strftime("%H:%M")

# 1. GET 기존값 전체
url = f"http://127.0.0.1:5176/departure/api/vehicle-extras?date={DATE}"
req = urllib.request.Request(url)
with urllib.request.urlopen(req, timeout=5) as resp:
    existing = json.loads(resp.read().decode("utf-8"))
extras = existing["extras"]

# 2. 수정할 호차만 갱신 (합산 + 시간)
extras["2"]["regions"]["EAST"] = extras["2"].get("regions",{}).get("EAST",0) + 3
extras["2"]["regions"]["GMH"]  = extras["2"].get("regions",{}).get("GMH",0) + 2
extras["2"]["plt"] = 10
extras["2"]["departTime"] = NOW   # ⚠️ 필수 — 출차시간
extras["2"]["pltTime"] = NOW      # ⚠️ 필수 — 출고시간

# 3. 전체 POST (기존 호차 모두 포함)
payload = {"date": DATE, "extras": extras}
req = urllib.request.Request(
    "http://127.0.0.1:5176/departure/api/vehicle-extras",
    data=json.dumps(payload).encode("utf-8"), method="POST"
)
req.add_header("Content-Type", "application/json")
with urllib.request.urlopen(req, timeout=5) as resp:
    json.loads(resp.read().decode("utf-8"))
```

> ⚠️ `POST /api/ls-data`에 `regions`를 넣으면 **무시됨**. 권역/파레트 저장은 반드시 `/api/vehicle-extras` 사용.
