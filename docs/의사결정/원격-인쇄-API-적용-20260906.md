# 원격 무음 인쇄 API — 데스크톱(Windows 실서버) 적용 지시서

**작성:** Hermes (Linux 개발 머신) — 2026-09-06
**대상:** 데스크톱 Windows에서 실행 중인 Hermes
**목적:** 데스크톱에 연결된 Canon G2010 프린터를, Linux 개발 머신(Hermes)이 원격 HTTP로 조작할 수 있게 한다.

---

## 1. 배경

- 데스크톱(Windows, 실사용) VF Django 서버가 `5176` 포트로 공인망(bonohouse.p-e.kr)에 노출되어 있다.
- Linux 개발 머신에는 프린터가 없다. 인쇄(권역지 PDF·EDI 전표 등)는 전부 데스크톱의 Canon G2010으로만 가능하다.
- 이번 커밋에 **인쇄 API 2개 엔드포인트**를 추가했다. 데스크톱 코드에 반영·재시작하면,
  Linux Hermes가 `POST http://bonohouse.p-e.kr:5176/api/print` 한 번으로 데스크톱 프린터를 무음 출력한다.

## 2. 변경 파일 (이 저장소 기준)

| 파일 | 변경 | 내용 |
|------|------|------|
| `backend/sales_api/print_views.py` | **신규** | 인쇄 엔진 + 뷰 2개 (Windows: os.startfile 무음 / Linux: lp 대비) |
| `backend/sales_api/urls.py` | 수정 | `print/status`, `print` 라우트 2개 추가 |
| `backend/config/settings.py` | 수정 | `VF_PRINT_TOKEN`, `REGION_DIR` env 허용 + settings 정의 |

## 3. 적용 방법 (둘 중 하나)

**A. 전체 pull (권장 — 개발본 최신 동기화)**
```bash
git pull origin main
```
> ⚠️ 주의: 이 저장소 main은 데스크톱보다 **약 37+ 커밋 앞서 있다** (배치도 로케이션 동적발행, 수동입력,
> 고정=핀, 좌표 통일 등 최근 개발분 포함). pull하면 그 변경이 모두 데스크톱 실사용에 반영된다.
> **실사용 반영이 부담되면 B 방식(파일 3개만 적용)을 택하라.**

**B. 인쇄 API 파일만 적용 (실사용 코드 보존)**
- 위 3개 파일을 데스크톱 코드베이스의 같은 경로에 복사/병합
- `urls.py`: `from . import print_views` 추가 + `path("print/status"...)`, `path("print"...)` 2줄 추가
- `settings.py`: allowed_keys에 `'VF_WRITE_TOKEN', 'VF_PRINT_TOKEN', 'REGION_DIR'` 추가 +
  `VF_PRINT_TOKEN = (os.environ.get("VF_PRINT_TOKEN") or "").strip()` 정의

## 4. 필수 설정 — backend/.env

```bash
# 1) 인쇄 토큰 생성 (값은 Linux 머신과 동일해야 함)
python -c "import secrets; print(secrets.token_hex(16))"
```
생성된 값을 `backend/.env`에 추가:
```
VF_PRINT_TOKEN=<생성값>
```
**⚠️ 이 값을 Linux 개발 머신의 Hermes에게 전달하라** (두 머신 .env에 같은 값이 있어야 원격 인쇄가 된다).

선택 — 권역지 폴더가 기본 경로가 아닐 때만:
```
REGION_DIR=E:\자주쓰는 문서\권역지
```
(기본값이 이미 `E:\자주쓰는 문서\권역지` 이므로 보통 생략 가능)

## 5. 의존성

Windows 인쇄는 `pywin32`(win32print)를 사용한다. 없으면 설치:
```bash
pip install pywin32
```
> 데스크톱 기존 스킬 기록: pywin32는 **python 3.13**에 설치돼 있음. VF backend가 사용하는
> python 버전에 없으면 해당 인터프리터로 설치할 것.

## 6. 서버 재시작 후 검증 (반드시 실측)

```bash
# 1) 서버 재시작 (gunicorn 5176)
# 2) 현황 조회 — Canon G2010이 printers에 보이는지 확인
curl "http://localhost:5176/api/print/status"
# 기대: { "platform": "Windows", "printers": ["...Canon G2010 series..."], "region_files": {"east":"EAST.pdf", ...} }

# 3) 1장 테스트 인쇄 (토큰 헤더 필수)
curl -X POST "http://localhost:5176/api/print" \
  -H "Content-Type: application/json" \
  -H "X-VF-Token: <VF_PRINT_TOKEN 값>" \
  -d '{"region":"east","copies":1}'
# 기대: { "ok": true, "spooled": 1, ... "note": "스풀러 전송 완료 — 출력물 확인 부탁드립니다" }
```
출력물 1장이 나오면 성공. 보고는 **"스풀러 전송 완료 → 출력물 확인 필요"**로 (인쇄 완료로 단정 금지).

## 7. API 규격

### GET /api/print/status (토큰 불필요)
```json
{ "platform": "Windows", "printers": [...], "default_printer": "...",
  "region_dir": "E:\\자주쓰는 문서\\권역지", "region_files": {"d":"DGU.pdf","e":"EAST.pdf",...},
  "token_set": true }
```

### POST /api/print (X-VF-Token 필수, 없으면 503/403)
```json
// 권역지 인쇄
{ "region": "east", "copies": 15 }
// 직접 파일 인쇄 (EDI 전표 등)
{ "path": "C:/temp/edi_1.pdf", "copies": 1 }
// 프린터 지정 (선택 — 미지정 시 Canon G2010 자동 교정)
{ "region": "west", "copies": 15, "printer": "Canon G2010 series" }
```
권역 약어: `d/dgu`, `e/east`, `g/gmh`, `j/gwj`, `m/middle`, `w/west`
copies 제한: 1~99. 10장 이상은 1.0초 간격으로 스풀러 누적.

## 8. 절대 규칙

- ❌ CDP shadow DOM 인쇄 버튼 클릭 → Chrome 인쇄 다이얼로그 팝업 금지 (기존 KPP 스킬 사고 사례)
- ❌ os.startfile 없는 다른 인쇄 방식으로 교체 금지 — 이 API는 스풀러 직접 전송(무음)이 목적
- ✅ 보고 전 `GET /api/print/status` 실측으로 프린터 확인 (간접 보고 금지)
- 파일은 **생성하지 말 것** — EAST/WEST.pdf 등 권역지 PDF는 이미 `E:\자주쓰는 문서\권역지\`에 존재
