# VF 제품번호 표기 규칙 — 20XX번 (2026-08-06 확정)

## 배경
320-A1-2-XX 대역 제품은 백 자리가 비어 있어 320-A1-1-XXX와 번호 충돌 발생.
예: 320-A1-2-34 → "234번"으로 표기하면 320-A1-1-234(진짜 234번)와 혼선.

## 규칙
- **320-A1-2-XX → "20XX번"으로 표기**
  - 320-A1-2-34 → **2034번**
  - 320-A1-2-64 → **2064번**
- **320-A1-1-XXX → "XXX번" 그대로**
  - 320-A1-1-264 → **264번**
- **2034번 ≠ 234번** — 서로 다른 제품

## 예시 (2026-08-06 C동 재고 기준)

| 표기 번호 | 실제 로케이션 | 제품명 | 구분 |
|-----------|--------------|--------|------|
| 2034번 | 320-A1-2-34 | 슬라이딩 옷정리 적층 트레이 중형 10개 | 2-대역 |
| 234번 | 320-A1-1-234 | (별도 제품) | 1-대역 |
| 264번 | 320-A1-1-264 | BOX_모던 해피박스 2P 블루+아이보리 | 1-대역 |

## 사용자 호출 방식
사용자(주현 님)는 "이천삼십사 번"으로 부름. 에이전트는 320-A1-2-34로 인식.
