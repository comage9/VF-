## 1. 목표 (구축 완료 정의)

1. **단일 Wiki 루트(SSOT)** 가 에이전트·Obsidian·Git에서 동일하게 쓰인다.  
2. 매 세션 **Tool-First**: `SCHEMA → index → log` 배향 후 작업.
