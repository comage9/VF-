# VF MCP 서버

## 목적
Hermes가 VF-new 지시를 **브라우저 탐색 없이** Django REST 1회 호출로 실행.

## 경로
- 서버: `E:/coding/skill/VF/vf-mcp-server/server.py`
- Hermes: `mcp_servers.vf` (config.yaml)
- API base: `http://127.0.0.1:5176` (`VF_API_BASE`)

## Tools → Hermes 이름
| Tool | Hermes 등록명(예상) |
|------|---------------------|
| vf_status | mcp_vf_vf_status |
| vf_departure_list | mcp_vf_vf_departure_list |
| vf_regions_add | mcp_vf_vf_regions_add |
| vf_plt_set | mcp_vf_vf_plt_set |
| vf_print_ls | mcp_vf_vf_print_ls |
| vf_print_kpp | mcp_vf_vf_print_kpp |
| vf_stock_lookup | mcp_vf_vf_stock_lookup |
| vf_production_list | mcp_vf_vf_production_list |
| vf_production_register | mcp_vf_vf_production_register |

## 실측 (2026-08-10)
- vf_status: ~150–500ms
- vf_stock_lookup 첫 호출 ~3s (specs 로드), 캐시 후 ~2ms
- 작업일 06:00 기준

## 사용 규칙
- 권역: POST `/departure/api/vehicle-extras` only, 기본 합산
- 약어 G=GMH M=MIDDLE D=DGU GZJ=GWJ
- 현재고 SoT: master/specs.current_stock
- 인쇄: LS/KPP printto (UI 클릭 비표준)
- Gateway 재시작 후 tool 노출
