# 제품배치도 서버 영속화 + 개선·보안 계획 (2026-08-23, 사용자 확정)

범위: A1~A5 전부, 보안 #2·#3 (ALLOWED_HOSTS 제외), 기능 #4~#8.

## A. 서버 영속화

### A1. 백엔드 모델 + 엔드포인트 (sales_api)
- 모델 `ProductDisplaySnapshot` (sales_api/models.py):
  - `version` (int, auto-increment per save), `payload` (TextField, JSON: data+layout+lineConfig+staging 통합), `payload_hash` (sha1, 중복 저장 방지), `saved_by` (CharField, 기본 "browser"), `created_at`.
- urls:
  - `GET /api/product-display/latest` → 최신 스냅샷 (없으면 `{found:false}`)
  - `POST /api/product-display` → payload 수신·저장 (직전과 hash 동일이면 저장 스킵, 직전 버전 반환)
  - `GET /api/product-display/history` → 최근 20개 (version, saved_by, created_at)
  - `POST /api/product-display/restore` → {version} 지정 → 해당 스냅샷 복사로 새 버전 생성 (복구 이력 보존)
- 보관 정책: 20개 초과 시 자동 삭제.
- 마이그레이션: `python manage.py makemigrations sales_api && migrate` (DB=db.sqlite3 개발복사본에서 검증 후 운영 반영).

### A2. 기존 localStorage 내용 = 서버 시드
- 프론트: 서버에 스냅샷 0건이면 현재 브라우저의 4개 키(`vf_product_display_v1`, `vf_product_display_layout_v1`, `vf_pd_line_config_v1`, staging 키)를 합쳐 최초 1회 POST → 기본 복원본 생성.

### A3. 변경 시 자동 저장
- 프론트: data/layout/lineConfig/staging 변경 시 localStorage 즉시(기존 유지) + 서버 POST **2초 디바운스**.
- 네트워크 실패 시: 로컬 보존 + 헤더에 "서버 저장 실패(로컬 보관 중)" 경고 표시. 재시도 3회.

### A4. 복구 기능
- 우측 패널에 "서버 버전" 버튼 → 히스토리 목록(최근 20, 버전/저장자/시각) 표시 → 선택 시 미리보기 후 복원(=A1 restore).
- 임시보관함 실수 삭제도 스냅샷 복원으로 해결.

### A5. 다중 브라우저 동기
- 저장: payload에 `savedAt` ISO시각 포함.
- 로드: 서버판 `created_at` > 로컬 `savedAt` 이면 서버판 우선 로드 (5초 폴링으로 백그라운드 갱신, 편집 중엔 적용 보류).

## B. 보안 (1번 ALLOWED_HOSTS 제외)

### B2. csrf_exempt 정리
- 원칙: 새 엔드포인트(A1)는 CSRF 정상 사용 (SPA는 X-CSRFToken 헤더, `ensure_csrf_cookie`).
- 기존 7곳(sales_api 5 + departure 2): 호출자 실측 후 분류 —
  - 브라우저 전용 호출 → CSRF 전환.
  - MCP/스크립트 호출(departure print API 등) → **현상 유지**(전환 시 인쇄 자동화 파괴 위험). 목록과 사유만 문서화.

### B3. 쓰기 토큰
- 환경변수 `VF_WRITE_TOKEN` 설정 시 쓰기 엔드포인트(A1 POST/restore)에 `X-VF-Token` 헤더 검증. 미설정 시 현행 유지(사내망 기본). 토큰은 서버 `.env`에 추가, 프론트는 `/api/product-display/config`에서 수령.

## C. 기능 개선

### C4. 라인 삭제·재배열
- 삭제: 추가된 라인(기본 라인 외) 삭제 버튼 → 라인 내 제품은 임시보관함 이관.
- 재배열: 수정 모드에서 라인 라벨 드래그 또는 ◀▶ 버튼으로 좌우 순서 변경 (레이아웃 x좌표 재계산).

### C5. LineOverride 편집 UI
- 수정 모드에 "라인 설정" 패널: 라인별 칸 수(count) 입력·숨김 슬롯(hiddenSlots) 체크·배지 텍스트. 저장 시 `vf_pd_line_config_v1` 갱신 + 서버 스냅샷 포함.

### C6. 동시 편집 가시성
- 헤더에 "마지막 저장: HH:MM:SS (저장자)" 표시 (A1 saved_by/created_at 활용).

### C8. 제품번호 중복 경고
- 마스터 로드 후 product_number 중복 SKU 목록을 툴팁에 "⚠ 동일번호·다른 바코드" 경고 배지.

## 검토 회신 반영 (2026-08-23, default 에이전트 — 위험 4건 보강)
1. **동시 편집 충돌 (중상)** → POST에 `base_version` 필드 추가: 서버 최신 버전과 불일치 시 409 + 서버판 반환, 프론트는 사용자 알림 후 재저장 (낙관적 락).
2. **시드 실패 영구화 (중)** → 시드 실패 시 3회 재시도, 실패 지속 시 헤더 경고 "서버 미동기(로컬 전용)" + 수동 재시도 버튼.
3. **20개 초과 삭제 (중)** → 삭제 전 복원 시 404 + 안내 메시지 명시. 보관 20개 유지하되 히스토리는 hash 중복 스킵으로 소진 방지.
4. **CSRF 전환 전 호출측 전수 목록화 (중상)** → Task 1 착수 전 `grep`으로 csrf_exempt 7곳 호출자 식별 목록 작성, 인쇄 API(departure)는 무조건 현상 유지, 회귀는 실제 인쇄까지 검증.
5. **복원 충돌** → 복원 전 현재 상태 자동 스냅샷(자동 저장) → 복원 실패/취소 시 되돌리기 가능.
