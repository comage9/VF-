# 로케이션 전역 검색 — 구현 계획

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 모든 페이지에서 로케이션 코드(예: `310-A1-E-32`)로 검색 시 해당 로케이션에 속한 모든 품목이 검색되도록 한다.

**Architecture:** Backend — BarcodeMaster.location → barcode → MasterSpec 역참조. Frontend — 각 페이지 검색창에 로케이션 문자열을 감지해 API `?location=` 파라미터로 전달, 또는 기존 `?q=` / `?search=` 에 통합.

**Tech Stack:** Django REST + React/TypeScript (shadcn/ui + TanStack Query)

```typescript
// 파일 상단 또는 lib/searchMatch.ts에 추가
function isLocationPattern(input: string): boolean {
  // 로케이션 패턴: 숫자-알파벳+숫자-알파벳-숫자  (예: 320-A1-1-164, 310-A1-E-32)
  return /^\d+[ -]?[A-Za-z]+\d*[ -]?\d*[ -]?[A-Za-z]?\d*$/.test(input.trim());
}
```

**Step 2: 검색 API 호출 로직 수정**

- Modify: `E:/coding/VF-new/frontend/client/src/lib/searchMatch.ts` (또는 신규 생성)

**Step 1: `searchMatch.ts` 에 location-aware matchesSearch 함수 추가**

```typescript
export function matchesSearchWithLocation(
  item: Record<string, any>,
  searchFields: string[],
  searchTerm: string
): boolean {
  if (!searchTerm.trim()) return true;
  
  // 로케이션 패턴 감지
  if (isLocationPattern(searchTerm)) {
    return (item.location || '').includes(searchTerm.trim());
  }
  
  // 기존 필드 기반 검색
  return matchesSearchInFields(item, searchFields, searchTerm);
}
```

**Step 2: `data-table.tsx` 수정**

기존 `matchesSearchInFields` 호출을 `matchesSearchWithLocation` 으로 교체. `item.location` 필드를 자동으로 검사하도록 함.
