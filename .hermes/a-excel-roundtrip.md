# 작업 지시: 제품배치도 A동 엑셀 업로드/다운로드 왕복

① 역할: React + TypeScript + SheetJS(xlsx) 전문가.

② 상황:
- 프로젝트: E:/coding/VF-new (Django 백엔드 + React 프론트). 프론트 = frontend/client (Vite).
- 대상 페이지: frontend/client/src/pages/product-display.tsx (제품배치도 페이지)
- A동 배치 데이터: frontend/client/src/pages/product-display-a-data.ts
  - `A_RANK_PLACEMENT: Record<string,string>` — zone id("A-L1-19" 등) → 제품번호 문자열(콤마 다품목 가능, 예 "8,35")
  - `A_ZONE_CAT: Record<string,string>` — zone id → 분류명
  - 제품번호 규칙: 320-A1-1-XXX → XXX번, 320-A1-2-XX → 2XXX번 (예 320-A1-2-34 → 2034)
- localStorage 키: `vf_product_display_v1`, 현재 버전 `__v: "rank-a-v25"`. localStorage의 data가 화면 실제 배치(서버 재시작과 무관하게 유지됨).
- 제품 마스터는 `/api/master/specs` 응답에서 `masterMap`(제품번호→{name, category_lg, ...})으로 이미 로드되어 있음.
- 의존성: `xlsx 0.18.5` 이미 package.json에 설치됨 (frontend/client). 추가 설치 금지.
- 사용자가 제공한 기준 엑셀 형식(시트명 "vf 품목 제베치도") 헤더:
  순위_1개월박스 | 분류 | 로케이션 | 제품명 | 바코드 | 1개월_출고박스 | 단수 | 로케이션(숫자) | (비고)
  - "로케이션" 열 = 320-A1-1-XXX 또는 320-A1-2-XX 형식
  - 데이터 행은 순위 순서대로 나열되어 있음 (순위 열 값이 연속이 아닐 수 있음)

③ 문제(구현할 것 — 전부 1개 작업):
A. **다운로드**: 제품배치도 페이지 상단(기존 버튼 영역 근처)에 "엑셀 다운로드" 버튼 추가.
   - 현재 localStorage의 A동 배치 상태를 위 엑셀 형식으로 내보냄.
   - 각 행: 순위=뱀모양 로케이션 번호(아래 ⑤ 공식), 분류=zone의 분류명, 로케이션=역변환된 320 로케이션 문자열, 제품명=마스터명(없으면 빈칸), 바코드=마스터 바코드, 1개월_출고박스=마스터의 최근 1개월 출고 박스(페이지에 이미 있는 계산값 사용, 모르면 0).
   - 역변환: 제품번호 N → "320-A1-1-N"; 2XXX(4자리, 2로 시작) → "320-A1-2-" + (XXX를 숫자로). 예 "2034" → "320-A1-2-34".
   - 뱀모양 로케이션 번호(1~114): 통로 쌍 (L1|L2)=1~38, (L3|L4)=39~76, (L5|L6)=77~114.
     공식: 통로 쌍 인덱스 p(L1|L2=0, L3|L4=1, L5|L6=2), slot s(1~19), base=p*38, block=2*(19-s)+1:
     - 홀수 slot: 왼쪽라인=block, 오른쪽라인=block+1 (L1|L2면 L1=block, L2=block+1)
     - 짝수 slot: 오른쪽라인=block, 왼쪽라인=block+1
     - 검증: L1-19→1, L2-19→2, L2-18→3, L1-18→4, ..., L1-1→37, L2-1→38
   - **페이지에 이미 구현된 로케이션 번호 계산 함수가 있으면 반드시 그것을 재사용할 것.**
   - 한 칸 다품목("8,35")은 콤마로 분리해 각 제품마다 1행씩, 같은 로케이션 번호로 출력.
   - 파일명: `A동_배치표_YYYYMMDD.xlsx`, 시트명 "vf 품목 제베치도".
   - 정렬: 로케이션 번호 오름차순.
B. **업로드**: 같은 영역에 "엑셀 업로드" 버튼(숨김 file input).
   - 위 형식 엑셀을 읽어서 A동 배치를 갱신. 매칭 키 = 로케이션 문자열(320-...)을 제품번호 규칙으로 변환.
   - 엑셀 행들을 순위(로케이션 번호) 오름차순으로 읽되, **행 순서 그대로 뱀모양 로케이션 1,2,3,... 번 칸에 순차 배치**(엑셀의 "로케이션(숫자)" 열 값이 곧 배치 순서). 한 칸 다품목은 같은 번호 행끼리 병합(콤마).
   - 기존 배치에 있었지만 새 엑셀에 없는 제품 → 페이지에 이미 있는 📦임시보관함으로 이동(기존 로직 재사용. 없으면 미배치 목록으로).
   - 적용 후 localStorage `__v`를 "rank-a-v26"으로 승격해서 사용자 브라우저에 반영.
   - 잘못된 파일(헤더 불일치)이면 alert로 안내하고 아무것도 변경하지 않음.
C. 완료 조건: `cd frontend/client && npx tsc --noEmit` 에서 **수정 파일 관련 에러 0** (프로젝트 기존 에러는 무시), `npm run build` 성공.

④ 결과물: 수정된 파일 목록 + 다운로드/업로드 동작 요약만 출력.
